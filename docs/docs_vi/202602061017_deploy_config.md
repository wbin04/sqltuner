# VAI TRÒ
Bạn là một Kỹ sư Backend Python cấp cao.
Mục tiêu của bạn là sửa đổi một **Ứng dụng Flask** hiện có (`llm-proxy/run.py`) để bao gồm **Ngrok Tunneling Tự động** và **Đồng bộ URL Supabase**.

# NGỮ CẢNH
- **Tệp Hiện tại:** `llm-proxy/run.py`.
- **Chức năng:** Chạy một máy chủ Flask trên cổng `11434`. Nó chấp nhận các yêu cầu từ Backend (cổng 8000) và gọi một mô hình LLM cục bộ (ví dụ: qua `ollama` hoặc logic nội bộ).
- **Yêu cầu Mới:**
  1. Khi script khởi động, tự động khởi động một **Ngrok Tunnel** cho cổng `11434`.
  2. Cập nhật bảng `app_config` trong Supabase với URL công khai Ngrok mới.
  3. Khi script dừng (Ctrl+C), tự động xóa URL trong Supabase và tắt tunnel.

# RÀNG BUỘC NGHIÊM NGẶT (QUAN TRỌNG)
1. **KHÔNG VIẾT LẠI TOÀN BỘ FLASK:** Giả sử người dùng có các route Flask hiện có (ví dụ: `@app.route(...)`). Không xóa chúng. Sử dụng bình luận như `# ... [Giữ các route hiện có ở đây] ...` để chỉ ra nơi mã của người dùng vẫn còn.
2. **KHÔNG CÓ ICON/EMOJI:** Giữ đầu ra thuần túy kỹ thuật.
3. **ĐẦU RA ĐƯỜNG DẪN TỆP:** Dòng ĐẦU TIÊN của phản hồi phải là: `llm-proxy/run.py`.
4. **PHỤ THUỘC:** Sử dụng `flask`, `pyngrok`, `supabase`, `python-dotenv`.
5. **THREADING:** Đảm bảo khởi tạo Ngrok xảy ra *trước* `app.run()` chặn luồng chính.
6. **NGÔN NGỮ:** Bình luận bằng tiếng Việt.

# HƯỚNG DẪN
Tạo mã đầy đủ cho `llm-proxy/run.py` theo luồng logic này:

## 1. Import & Cấu hình
- Import các thư viện cần thiết (`flask`, `pyngrok`, `supabase`, `dotenv`, `atexit`, `signal`).
- Tải `.env` từ thư mục cha (`../.env` hoặc đường dẫn tương đối).
- Khởi tạo Supabase Client.

## 2. Hàm Hỗ trợ (Vòng đời Ngrok)
- `init_tunnel()`:
    - Đặt mã thông báo xác thực Ngrok.
    - Kết nối đến cổng `11434`.
    - Cập nhật Supabase: `UPDATE app_config SET value = 'public_url' WHERE key = 'llm_url'`.
    - In URL Công khai ra bảng điều khiển.
- `cleanup()`:
    - Cập nhật Supabase: `UPDATE app_config SET value = '' WHERE key = 'llm_url'`.
    - Tắt tiến trình Ngrok.

## 3. Khối Thực thi Chính
- Khởi tạo Flask `app = Flask(__name__)`.
- **[Trình giữ chỗ]**: Chèn bình luận chỉ ra nơi các route xử lý LLM hiện có được đặt.
- **Logic Khởi động**:
    - Gọi `init_tunnel()` ngay trước khi chạy máy chủ.
    - Đăng ký trình xử lý `atexit` hoặc `signal` để gọi `cleanup()` khi tắt.
- **Chạy Máy chủ**: Gọi `app.run(port=11434)`.
