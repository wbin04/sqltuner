# Task: Thay thế clarification text bằng ClarificationBlock UI trong Chat

## Vấn đề hiện tại

Khi backend trả về clarification questions, nội dung hiện như plain text trong chat bubble:

~~~
Before designing the schema, I have a few questions:
1. What specific entities should be included?
   Options: Products, Customers, Employees
2. What operations do you expect?
   Options: Inventory management, Sales tracking
Please answer these questions and I'll generate the schema.
~~~

Cần thay bằng UI interactive với buttons chọn options + input tự do,
tương tự step 2 của `GenerateSchemaModal` hiện có.

## Cấu trúc hiện tại cần hiểu

**`useEditorLogic.ts`** đã có:
- `pendingClarification` state: `{ questions: Array<{q, options?}>, originalMessage }`
- `parseClarificationQuestions(content)` — parse text thành array questions
- `handleSendMessage` — detect `isClarificationReply`, gửi kèm `clarification_answers`
- Set `pendingClarification` trong `onSuccess` khi response chứa `'Before designing the schema'`

**`ChatArea.tsx`** đã có:
- Props `onApplySchemaToSandbox`, `isSimulationWorkspace`
- Render `SchemaBlock` khi `message.schema_generated` có giá trị
- Hiện render plain text message cho clarification — **đây là chỗ cần fix**

### 1. Tạo file mới `frontend/src/components/editor/ClarificationBlock.tsx`

~~~tsx
import { useState } from 'react';
import { Sparkles, ChevronRight, Loader2 } from 'lucide-react';
import { cn } from '../../lib/utils';

interface ClarificationQuestion {
  q: string;
  options?: string[];
}

interface Props {
  questions: ClarificationQuestion[];
  onSubmit: (answers: Array<{ q: string; answer: string }>) => void;
  isLoading?: boolean;
}

export function ClarificationBlock({ questions, onSubmit, isLoading = false }: Props) {
  // answers[i] = array of selected options + free text for question i
  const [selected, setSelected] = useState<Record<number, string[]>>({});
  const [freeText, setFreeText] = useState<Record<number, string>>({});

  const toggleOption = (qIdx: number, option: string) => {
    setSelected(prev => {
      const current = prev[qIdx] || [];
      const exists = current.includes(option);
      return {
        ...prev,
        [qIdx]: exists ? current.filter(o => o !== option) : [...current, option],
      };
    });
  };

  const handleSubmit = () => {
    const answers = questions.map((q, idx) => {
      const parts: string[] = [...(selected[idx] || [])];
      const extra = freeText[idx]?.trim();
      if (extra) parts.push(extra);
      return {
        q: q.q,
        answer: parts.join(', ') || 'No preference',
      };
    });
    onSubmit(answers);
  };

  const hasAnyAnswer = questions.some((_, idx) =>
    (selected[idx]?.length ?? 0) > 0 || freeText[idx]?.trim()
  );

  return (
    <div className={cn(
      'rounded-xl border overflow-hidden',
      'border-purple-200 dark:border-purple-800',
      'bg-purple-50 dark:bg-purple-950/30'
    )}>
      {/* Header */}
      <div className="flex items-center gap-2 px-4 py-3 border-b border-purple-200 dark:border-purple-800 bg-purple-100 dark:bg-purple-900/40">
        <Sparkles className="w-4 h-4 text-purple-600 dark:text-purple-400" />
        <span className="text-sm font-semibold text-purple-700 dark:text-purple-300">
          A few questions before generating
        </span>
      </div>

      {/* Questions */}
      <div className="divide-y divide-purple-100 dark:divide-purple-900/50 px-4 py-3 space-y-4">
        {questions.map((q, idx) => (
          <div key={idx} className={idx > 0 ? 'pt-4' : ''}>
            <p className="text-sm font-medium text-gray-800 dark:text-gray-200 mb-2">
              {idx + 1}. {q.q}
            </p>

            {/* Option chips */}
            {q.options && q.options.length > 0 && (
              <div className="flex flex-wrap gap-2 mb-2">
                {q.options.map((opt, optIdx) => {
                  const isSelected = (selected[idx] || []).includes(opt);
                  return (
                    <button
                      key={optIdx}
                      type="button"
                      onClick={() => toggleOption(idx, opt)}
                      disabled={isLoading}
                      className={cn(
                        'rounded-full border px-3 py-1 text-xs transition-colors disabled:opacity-50',
                        isSelected
                          ? 'border-purple-400 bg-purple-100 text-purple-700 dark:bg-purple-900 dark:text-purple-300 dark:border-purple-500'
                          : 'border-gray-300 text-gray-600 hover:border-purple-400 dark:border-gray-600 dark:text-gray-400 dark:hover:border-purple-500'
                      )}
                    >
                      {isSelected && <span className="mr-1">✓</span>}
                      {opt}
                    </button>
                  );
                })}
              </div>
            )}

            {/* Free text */}
            <input
              type="text"
              placeholder="Add more details... (optional)"
              value={freeText[idx] || ''}
              onChange={e => setFreeText(prev => ({ ...prev, [idx]: e.target.value }))}
              disabled={isLoading}
              className={cn(
                'w-full rounded-lg border px-3 py-1.5 text-sm',
                'border-gray-300 dark:border-gray-600',
                'bg-white dark:bg-gray-800',
                'text-gray-900 dark:text-gray-100',
                'placeholder:text-gray-400 dark:placeholder:text-gray-500',
                'focus:outline-none focus:ring-2 focus:ring-purple-500',
                'disabled:opacity-50'
              )}
            />
          </div>
        ))}
      </div>

      {/* Footer */}
      <div className="flex items-center justify-between px-4 py-3 border-t border-purple-200 dark:border-purple-800">
        <p className="text-xs text-gray-400 dark:text-gray-500">
          Select options or type your own answers
        </p>
        <div className="flex gap-2">
          {/* Skip — generate without answers */}
          <button
            type="button"
            onClick={() => onSubmit(questions.map(q => ({ q: q.q, answer: 'No preference' })))}
            disabled={isLoading}
            className="px-3 py-1.5 text-xs text-gray-500 hover:text-gray-700 dark:text-gray-400 dark:hover:text-gray-200 disabled:opacity-50 transition-colors"
          >
            Skip
          </button>

          {/* Generate */}
          <button
            type="button"
            onClick={handleSubmit}
            disabled={isLoading}
            className={cn(
              'flex items-center gap-1.5 px-4 py-1.5 rounded-lg text-sm font-medium text-white transition-colors',
              'bg-purple-600 hover:bg-purple-700 disabled:opacity-50'
            )}
          >
            {isLoading
              ? <Loader2 className="w-3.5 h-3.5 animate-spin" />
              : <ChevronRight className="w-3.5 h-3.5" />
            }
            {isLoading ? 'Generating...' : 'Generate Schema'}
          </button>
        </div>
      </div>
    </div>
  );
}
~~~

const handleSubmitClarification = useCallback(
  async (answers: Array<{ q: string; answer: string }>) => {
    if (!pendingClarification) return;

    // Tạo summary message từ answers để hiện trong chat
    const answerSummary = answers
      .filter(a => a.answer && a.answer !== 'No preference')
      .map(a => `${a.q}: ${a.answer}`)
      .join('; ');

    const displayMessage = answerSummary || 'Generate schema with default settings';

    await sendMessageMutation.mutateAsync({
      message: displayMessage,
      clarification_answers: answers,
    });

    setPendingClarification(null);

## Flow hoàn chỉnh sau khi implement

~~~
User: "tôi muốn tạo database quản lý cửa hàng tạp hoá"
         ↓
Backend detect is_schema_design=True, message ngắn → trả về clarification
         ↓
ChatArea nhận message có "Before designing the schema..."
→ KHÔNG render plain text bubble
→ Render ClarificationBlock với option chips + free text
         ↓
User chọn options: [Products, Customers] + type thêm "với tồn kho"
User click "Generate Schema"
         ↓
useEditorLogic.handleSubmitClarification() gọi sendMessage với:
  message: "Products, Customers: với tồn kho"
  clarification_answers: [{q: "...", answer: "Products, Customers, với tồn kho"}]
         ↓
Backend nhận clarification_answers → generate schema đầy đủ
         ↓
ChatArea render SchemaBlock với tables + columns + Apply to Sandbox button
~~~
